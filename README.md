## Featured Project

### AgriLink — Digital Agricultural Commerce

<p align="center">
  <a href="https://agrilink.ao">
    <img src="https://img.shields.io/badge/AgriLink-agrilink.ao-087e8b?style=for-the-badge&logo=googlechrome&logoColor=white" alt="AgriLink website" />
  </a>
  <a href="https://github.com/TheRuralTeam/agrilinks">
    <img src="https://img.shields.io/badge/Source_Code-GitHub-181717?style=for-the-badge&logo=github&logoColor=white" alt="AgriLink source code" />
  </a>
</p>

**AgriLink** is an agricultural commerce platform designed to connect producers, suppliers, buyers, and transporters through digital tools that facilitate product discovery and commercial coordination.

The project aims to make agricultural trade more accessible by bringing product listings, purchasing workflows, and logistics closer together.

**My contribution:** Full-stack software development, alongside product and operational responsibilities, helping evolve the platform's functionality and technical capabilities.
